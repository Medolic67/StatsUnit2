FRQ Templates

Fill-in-the-blank frameworks for the most common written responses in Unit 2. Always answer in context.

Sampling

Describe an SRS
"Label each [individual] from 1 to [N]. Use a random number generator to select [n] unique numbers between 1 and [N], ignoring repeats. The [individuals] with the matching labels are the sample."
Describe a stratified sample
"Split the [population] into strata by [variable]. Within each stratum, label the individuals and use a random number generator to select an SRS of [n_i] unique individuals (proportional to stratum size). Combine the selected individuals."
Describe a cluster sample
"Each [group] is a cluster. Label the clusters 1 to [k]. Use a random number generator to select [m] clusters. Survey every individual in the selected clusters."
Describe a systematic sample
"Label individuals 1 to N. Compute k = N/n = [k]. Use a random number generator to pick a starting number from 1 to k. Select that individual and every k-th individual after, until n are chosen."
Why stratify / cluster / systematic?
Stratify: guarantees every group is represented and lowers variability (when groups differ on the response). Cluster: cheaper and easier to carry out. Systematic: easy and spreads the sample across the whole population.

Bias

Identify and explain bias
"This is [undercoverage / nonresponse / response bias] because [context: who is left out, who didn't respond, or why answers are inaccurate]. The estimate will likely be [too high / too low] because [reason]."
Good vs bad estimates (bias vs variability)
"The method has [low/high] bias because the estimates are centered [at / away from] the true value of [parameter], and [low/high] variability because the estimates are [close together / spread out]."

Studies and experiments

Observational or experiment?
"This is an [experiment / observational study] because researchers [imposed treatments on the subjects / only observed and did not impose any treatment]."
Experimental units, treatments, response
"The experimental units are [who/what]. The treatments are [levels of the explanatory variable]. The response variable is [measured outcome]."
Random assignment
"Label the [N] [units] 1 to [N]. Use a random number generator to select [N/2] unique numbers. Those units get [treatment 1]; the remaining units get [treatment 2]."
Purpose of random assignment
"It creates roughly equivalent groups, so any difference in [response] can be attributed to the treatments (not to confounding variables)."
Purpose of a control/placebo group
"It provides a baseline for comparison, so we can tell whether [treatment] actually changes [response]."
Blinding
"Subjects don't know which treatment they receive (and the evaluator doesn't either, making it double-blind) so that expectations can't influence the results."
Why block?
"[Blocking variable] may affect [response]. Blocking by [variable] controls for it and reduces variability within each block, making it easier to detect differences between the treatments."
Matched pairs
"Each [subject] receives both treatments in random order (determined by a coin flip), or subjects are paired by [variable] and one in each pair is randomly assigned each treatment."

Outline checklist (drawn diagram)

  • Start with the number of units (e.g. "300 subjects").
  • Arrow to random assignment (or to blocks first, then random assignment within each block).
  • Show group sizes that are about equal, with each treatment labeled.
  • Arrow into compare [response variable]. For blocks: compare within each block, then combine.

Inference

What does one dot represent?
"One simulated random assignment (or sample), assuming [no effect], and the resulting [difference of means / percent]."
Is it statistically significant?
"In the simulation, [x]% of the dots were as extreme or more extreme than our actual result of [value]. Because [x]% is [less/more] than 5%, the result [is / is not] statistically significant, so we [do / do not] have convincing evidence that [treatment] causes [change]."
Scope of inference
"Because [a random sample was / no random sample was] used, we [can generalize to all population / cannot generalize beyond the sample]. Because [random assignment was / was not] used, we [can conclude causation / can only conclude an association]."
