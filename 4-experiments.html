Designing Experiments

Lessons 2.6 – 2.7: Principles, random assignment, blinding, and experimental designs

2.6 Well-designed experiments

The four principles

PrincipleMeaningWhy
1. ComparisonUse 2 or more treatments (often including a control or placebo group)Baseline to compare against
2. Random assignmentUse chance to assign units to treatment groupsMakes groups roughly equivalent → lets us show causation
3. ReplicationMore than 1 unit in each treatment groupReduces the role of chance; shows the effect isn't a fluke
4. ControlKeep other variables constant for all groups (same conditions, same teacher, same time)Prevents confounding
Control group vs control principleA control group receives no treatment or a placebo and gives baseline data. The control principle means keeping everything else equal. Say which one you mean.

Random assignment: Label → Randomize → Assign

Model: 1200 cows, 3 treatments (eyes, crosses, nothing)Label the cows 1 to 1200. Use a random number generator to get 400 unique numbers; those cows get the eyes. Generate 400 different numbers; those cows get crosses. All remaining cows get no marks.
Purpose: creates roughly equivalent groups so we can determine whether the treatments cause deaths to decrease.
  • Two groups, 180 students: label 1–180, RNG picks 90 unique numbers for the review sheet, the rest study alone (or names in a hat).
  • Always say unique / ignore repeats.

Placebo and blinding

Placebo effectWhen a fake treatment (placebo) works because people believe they got a real one.
Single-blindSubjects don't know which treatment they're getting or the evaluators/experimenters don't know.
Double-blindBoth subjects and the people interacting with them/measuring the response don't know.

Importance of blinding: prevents expectations from changing behavior or how results are recorded (bias). Importance of placebo: lets us separate the real effect of the medicine from the effect of just believing in treatment.

Worked: cows with eyes painted on their rears
  • Control group (nothing painted) provides baseline data to compare to: 15 deaths vs 4 (crosses) vs 0 (eyes).
  • Outline: 1200 cows → random assignment → Group 1 (400) eyes / Group 2 (400) crosses / Group 3 (400) none → compare number of deaths.
Worked: What's wrong with these experiments?
  • Mr. Wilcox beard oil: no comparison/control (don't know growth without oil), only one month (no replication). Fix: measure a month without oil as control; do multiple months/subjects.
  • Track coach: athletes chose their workout → observational study. Fix: number athletes 1–120, RNG picks 60 unique numbers for the strength workout, others relaxed. Random assignment lets us show the workout caused faster times.
  • Smart pills: students knew which treatment they got. Fix: no labels on pills (single blind); double-blind if the teacher also doesn't know who got which.

2.7 Selecting an experimental design

DesignHow it worksWhen to use
Completely randomized design (CRD)Randomly assign all units to treatmentsNo obvious variable that affects the response
Randomized block designSeparate units into blocks (groups of similar units), then randomly assign treatments within each block. Compare within blocks, then combine.A variable (age, grade level, location) is known to affect the response
Matched pairs designA special block of size 2. Either pair similar subjects and randomly assign treatments within each pair, or each subject gets both treatments in random order.Natural pairs or before/after / two sides of body
Block ≠ strataBlocks are used in experiments (randomly assign treatments within blocks). Strata are used in sampling (randomly select individuals from each stratum). Notes: "*not strata*".

Why block?

  • Controls a confounding variable by making sure every treatment appears within each type of unit.
  • Within each block there is lower variability in the response, making it easier to determine which treatment is most effective.
  • Choose blocks using the variable that has the largest effect on the response.
  • Purpose of random assignment within each block: balance out any remaining unknown variables so groups are comparable within the block.
  • Matched pairs advantage over CRD: controls for subject-to-subject variability since each subject (or a very similar pair) serves as its own comparison.

HW 2.7 answers
  • Q1: (a) In a CRD, all units are randomly assigned together; in a block design, units are first grouped into blocks and random assignment occurs within each block. (b) Each pair is a block (of size 2) with randomization of treatments within the pair.
  • Q2 Alaska teachers: (a) Label teachers 1–300, RNG for 150 unique numbers → bonus; others no bonus; compare retention rates. (b) Elementary, middle, and high school teachers may have different retention rates (school level is related to getting the bonus by chance and affects retention). (c) Randomized block design with blocks elementary / middle / high. (d) Within each group of 100, label 1–100 and RNG for 50 unique numbers → bonus; rest no bonus.
  • Q3 shin guards: (a) Units: the 20 players (or each leg); treatments: new vs standard shin guard; response: comfort rating 1–10. (b) Matched pairs design: each player tries both, one on each leg (each player is a block of size 2). (c) For each player flip a coin: heads, new guard on left shin and standard on right; tails reverse. (d) Controls for differences between players (variability), so comparisons are more precise.
  • Q4 physical therapist: (a) Block by age: age is more likely to affect joint pain and mobility; appointment time is not related to response. (b) Reduces variability and controls age as a confounder, making it easier to detect differences between exercises.
  • Q5 irrigation: (a) Block so that plots in a block are similar. Because the stream could make nearby plots wetter, the blocks should separate plots next to the stream from those far from it (Option 1 in the diagram, if the stream runs along one side). (b) Block A (plots near stream): randomly assign 3 plots to type 1 and 3 to type 2; Block B (plots away from stream): same. Compare growth within each block, then combine. (c) Random assignment within each block balances the remaining differences among plots (soil, sunlight).
  • Q6 MCQ: light treatments randomly assigned to flights within each block (B). Q7 MCQ: each pilot received both breakfasts in random order → experiment with matched pairs design (C).
